# annotools

MCP server and Python library that let agents view and annotate images, video, and audio within an
MLLM token budget: downscale, crop-zoom, grid guide lines, and BBox / keypoint / polygon / segmentation
overlays.

- Usage, installation, and the tool table: [README](https://github.com/hoshiori-dev/annotools#readme)
  ([中文](https://github.com/hoshiori-dev/annotools/blob/main/README.zh.md)).
- Tool specifications (parameters, metadata keys, acceptance criteria):
  [`.agents/knowledge/spec/`](https://github.com/hoshiori-dev/annotools/tree/main/.agents/knowledge/spec).
- Architecture and recorded decisions:
  [`ARCHITECTURE.md`](https://github.com/hoshiori-dev/annotools/blob/main/ARCHITECTURE.md).
- Skills: `npx skills add hoshiori-dev/annotools`.

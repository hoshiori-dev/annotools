# Security Policy

## Reporting a vulnerability

Use private vulnerability reporting: https://github.com/hoshiori-dev/annotools/security/advisories/new.
Never report vulnerabilities through public issues, discussions, or pull requests.

- Acknowledgement within 7 days; triage by the repository maintainers.
- Supported versions: the latest release and `main`.
- Disclosure: coordinated; we publish an advisory once a fix is released.
